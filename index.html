Recommended workflow

最适合你的用法

  1. 先用快捷指令

    把常用命令做成 Shortcut，给它分配键盘快捷键。

  2. 切输入法用专用 helper

    直接调用 macOS 输入法接口，比模拟 Command + Space 更稳。

  3. 以后需要更强再装 Raycast

    Raycast 更适合普通用户：搜索、点击、绑定快捷键都很顺手。

Example script

切到微信输入法示例

swiftc scripts/select-wetype.swift -o select-wetype
./select-wetype

这个示例会直接选择微信输入法中文拼音，不依赖 Spotlight 或键盘快捷键设置。
